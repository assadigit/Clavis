## v1.0.1 — UI bug-fix release (user-reported)

- Re-cloned the repo (sandbox reset); re-verified the whole v1.0.0 tree builds.
- **4 user-reported bugs, all root-caused and fixed:**
  1. *Hamburger icon that never opened anything*: the custom `.clavis-btn{display:inline-flex}` lived in UNLAYERED CSS, which beats Tailwind's layered utilities — so `md:hidden` could never hide the mobile-nav button on desktop widths (and on desktop widths the drawer it opens is invisible anyway, since the sidebar is already a column). Fix: all Clavis recipes now live in `@layer components` (below utilities) in both editions; the Manager's `MinWidth` is raised 760 → 800 so the window can never slip under the 48rem (768px) three-column breakpoint.
  2. *Settings page out of viewport*: the desktop Manager sized itself `height:100dvh` inside the desk frame, which is already inset by the 32px shadow pad → the app was 64px taller than the visible rounded frame and `overflow:hidden` clipped the bottom of every view (Settings' Data/About sections were unreachable; both empty states sat visibly above center). Fix: `height:100%` of the frame; leftover web-edition tray-clearance `paddingBottom` removed from the detail column and Settings; modals size against `--clavis-modal-vh` (window minus 2×pad).
  3. *"Your keys…"/"Nothing selected" alignment + confusing*: both were pushed off-center by the clip above. Also reworked the empty states for a brand-new user: empty store → "Welcome to Clavis" + shortcut keycap hint (no duplicate CTA); entries exist but nothing selected → "Nothing selected / Pick an entry from the list to see it here." + New buttons.
  4. *Category "…" menu collided with rows*: menus used `--glass-bg` (10% white) — over dense sidebar rows the underlying text bled through as a collision. Fix: `.clavis-menu` now paints a near-opaque raised surface `color-mix(in srgb, var(--solid-surface-raised) 96%, transparent)` (token-derived; falls back to the solid token where color-mix is unsupported), keeping the glass blur for depth.
- Frontend rebuilt (tsc clean); icons/syso regenerated with 1.0.1.0 version info (byte-verified in the PE).
- All 68 Go tests still green (`go test ./internal/... -count=1`).
- End-to-end re-verified in Wails server mode against the real Go backend: hamburger `display:none` at 1000×680 and `display:flex` < 768px with the drawer + scrim + close button; app shell fits the desk frame in both normal (32px pad) and maximized (edge-to-edge) states; Settings scrolls fully to About inside the frame; category menu computes to rgba(30,45,80,0.96); fresh store shows the new Welcome state; item created through the UI persists to `clavis-data.json`; popup lists it with a masked preview; zero console/page errors.
- Rebuilt: `Clavis.exe` (13.8 MB, PE32+ GUI), `Clavis-Setup-1.0.1.exe` (NSIS 3.11, 7.7 MB), `Clavis-Portable-1.0.1.exe`.
